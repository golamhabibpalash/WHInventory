# 12 — Utilities: To‑do Lists

Menu group: **Utilities**.

A lightweight place to keep task lists inside uStock — for example a receiving
checklist, a month-end routine, or follow-ups on a customer. It is not linked to stock
or documents; it is a simple notepad of lists and their items.

Generic list / add / edit behaviour: [Chapter 13](13-everyday-tasks-and-conventions.md).

---

## 12.1 Todo (the list)

### Purpose
A named list that groups related items.

### Where to find it
`Utilities ▸ Todo`

### Key fields
| Field | Notes |
|-------|-------|
| **Name** | The list title (e.g. `Month-end close`). |
| **Description** | Optional detail about the list's purpose. |

### How to create a list
1. `Utilities ▸ Todo` ▸ **Add**.
2. Enter a **Name** and optional **Description**. **Save**.

---

## 12.2 Todo Item (the entries)

### Purpose
A single task belonging to a list.

### Where to find it
`Utilities ▸ Todo Item`

### Key fields
| Field | Notes |
|-------|-------|
| **Todo** | The list this item belongs to. |
| **Name** | The task (e.g. `Reconcile bank`). |
| **Description** | Optional notes / steps. |

### How to add items
1. `Utilities ▸ Todo Item` ▸ **Add**.
2. Choose the **Todo** list, enter the item **Name** and optional **Description**.
   **Save**.
3. Repeat for each task. You can also manage items from within the Todo list record.

### Rules & tips
- To-do lists are shared within your organisation, subject to the `Todos` role
  (Chapter 10). They are visible to anyone who has that area.
- Remove an item with **Delete** when it is done, or keep a "Done" list and move items
  by editing their **Todo**.
