# 00 — About This Manual

## 0.1 Purpose

This manual explains how to operate **uStock**, an inventory and warehouse management
system. It describes every screen, every feature and the day-to-day activities the
software supports, in non-technical language.

It does **not** cover installing or hosting the software. That information lives in the
project's technical documentation (`README`, `CLAUDE.md`, `AGENTS.md`).

## 0.3 How the manual is organised

The manual follows a common international structure for software user documentation:

1. **Front matter** — this chapter (purpose, audience, conventions, document control).
2. **Overview** — Chapter 01 explains concepts and vocabulary.
3. **Getting started** — Chapter 02 gets you signed in and oriented.
4. **Task chapters** — Chapters 03–12 are grouped by job area. Each feature is
   described with the same five headings so you always know where to look:
   - **Purpose** — what the feature is for.
   - **Where to find it** — the menu path.
   - **Key fields** — the information you enter, in plain terms.
   - **How to…** — numbered step-by-step procedures.
   - **Rules & tips** — limits, automatic behaviour and good practice.
5. **Reference** — Chapter 13 (shared conventions), Chapter 14 (troubleshooting),
   Chapter 15 (glossary).

## 0.4 Conventions used in this manual

| Convention | Meaning |
|------------|---------|
| **Bold** | A button, menu item, field label or status exactly as shown on screen. |
| Menu path shown as `Sales ▸ Sales Order` | Open the **Sales** group in the left menu, then click **Sales Order**. |
| *Italic* | A term defined in the [Glossary](15-glossary.md). |
| `Monospace` | Text you type exactly, or an example value. |
| 🔒 | An action that normally requires administrator access. |
| ⚠️ | A warning — read before acting. |
| Steps `1. 2. 3.` | Do them in order. |
| Dates like `31/12/2025` | Day / Month / Year — the format uStock shows everywhere. |

## 0.5 Screen layout terms

- **Left menu** (or *sidebar*) — the dark vertical list of groups and screens on the
  left. You can drag items within a group to reorder them for yourself.
- **Grid** — a table of records with search, filter, sort, grouping and export.
- **Panel** / **form** — the pop-up or side area where you add or edit one record.
- **Toolbar** — the row of buttons above a grid (**Add**, **Edit**, **Delete**,
  **Excel Export**, **Search**, and screen-specific buttons).

## 0.6 Versioning rule for this manual

Use a three-part version number `MAJOR.MINOR.PATCH`:

- **MAJOR** — the manual was reorganised, or a whole product area changed.
- **MINOR** — a feature was added, removed or changed in behaviour.
- **PATCH** — wording, typo, clarification or formatting only.
