# 15 — Glossary

Terms are listed alphabetically. Where a fuller explanation exists, the chapter is noted.

| Term | Meaning |
|------|---------|
| **Adjustment** | A manual increase (*Positive Adjustment*) or decrease (*Negative Adjustment*) of stock for a reason other than a purchase or sale. See Chapter 07. |
| **Archived** | A document status meaning "keep for history, hide from active lists". No further effect on stock. See Chapter 13. |
| **Audit Log** | The automatic record of who created, changed or deleted each record. See Chapter 11. |
| **Barcode** | A scannable code stored on a product for quick look-up. |
| **Brand** | The manufacturer/brand classification of a product. See Chapter 04. |
| **Cancelled** | A document status meaning "voided". Any stock effect it had is reversed. See Chapter 13. |
| **Confirmed** | A document status meaning "final and in force". Its stock movement takes effect. See Chapter 13. |
| **Cost-plus** | A pricing method: selling price = cost (WAC) plus a markup percentage or amount. See Chapter 08. |
| **Customer** | An organisation or person you sell to. See Chapter 05. |
| **Customer Category** | A classification of customers used for filtering/reporting; does not affect price. See Chapter 05. |
| **Customer Group** | A grouping of customers that can be linked to a Price Policy for automatic pricing. See Chapter 05 / 08. |
| **Delivery Order (DO)** | The document recording goods leaving your warehouse to a customer. Confirming it reduces stock. See Chapter 05. |
| **Draft** | A document status meaning "being prepared". Freely editable; no effect on stock. See Chapter 13. |
| **Goods Receive (GR)** | The document recording goods arriving from a supplier. Confirming it increases stock. See Chapter 06. |
| **Grid** | A table of records on screen with search, filter, sort, grouping and Excel export. See Chapter 13. |
| **Gross Margin %** | A pricing method: the price is set so that a chosen percentage of it is profit. See Chapter 08. |
| **Inventory transaction** | One line in the stock ledger: a signed movement of one product in one warehouse, linked to the document that caused it. See Chapter 01 / 09. |
| **KPI** | "Key Performance Indicator" — a headline figure on the Dashboard. See Chapter 02. |
| **Ledger** | The complete set of inventory transactions. Stock on hand is the sum of the confirmed ones. |
| **Number Sequence** | The rule that generates a document's reference number (prefix + running number + suffix). See Chapter 03. |
| **Physical product** | A real, stock-controlled item (the default). The opposite is a *non-physical* / service product, which is billed but never held in stock. See Chapter 04. |
| **Price band** | The **Min Selling Price** to **Max Selling Price** range on a product. Sale prices must stay within it unless overridden. See Chapter 04 / 08. |
| **Price Policy** | A named, dated price list that holds product prices and can be switched on/off as a whole. See Chapter 08. |
| **Product** | The master record for anything you buy, hold or sell. See Chapter 04. |
| **Product Group** | A category for products, used for filtering and reporting. See Chapter 04. |
| **Product Price** | One product's price inside one Price Policy, defined by a calculation method. See Chapter 08. |
| **Promotion** | A short-term price or discount for one product, between two dates, overriding other prices. See Chapter 08. |
| **Purchase Order (PO)** | Your formal order to a supplier. Drives goods receipt. Has extra progress labels (Open, Partially Received, Fully Received, Closed). See Chapter 06. |
| **Purchase Return** | Goods sent back to a supplier. Confirming it reduces stock. See Chapter 06. |
| **Quantity Break** | A stepped price inside a Product Price: a different per-unit price above a quantity threshold. See Chapter 08. |
| **Role** | A grant of access to one area of the menu. Roles are fixed; administrators assign them to users. See Chapter 10. |
| **Sales Order (SO)** | A customer's order. Drives delivery, payments and sales reporting. Does not itself move stock. See Chapter 05. |
| **Sales Return** | Goods a customer sends back. Confirming it increases stock. See Chapter 05. |
| **Scrapping** | Writing off damaged/expired stock that is being disposed of. Reduces stock. See Chapter 07. |
| **Slug** | The short code in an organisation's web address (e.g. `acme`). See Chapter 02 / 11. |
| **Soft delete** | Deletion that hides a record but keeps it in the database for audit. There is no on-screen undo. See Chapter 13. |
| **Stock Count** | A physical count of a warehouse that corrects system figures to match reality. See Chapter 07. |
| **Stock on hand** | The current quantity of a product in a warehouse = sum of its confirmed inventory transactions. |
| **System warehouse** | One of six built-in virtual warehouses (Customer, Vendor, Transfer, Adjustment, Stock Count, Scrapping) used as the "other end" of every movement. Never edit or delete them. See Chapter 01 / 04. |
| **Tax** | A named percentage applied to an order's net amount. See Chapter 03. |
| **Tenant** | One independent organisation/workspace on a multi-organisation installation. See Chapter 01 / 11. |
| **Transfer In** | Receiving goods from a Transfer Out into the destination warehouse. See Chapter 07. |
| **Transfer Out** | Sending goods from one of your warehouses towards another; they sit "in transit" until received. See Chapter 07. |
| **Unit Measure** | The unit a product is counted in (piece, box, kg…). See Chapter 04. |
| **User Activity Log** | The record of sign-ins, sign-outs and pages visited. See Chapter 11. |
| **UTC** | "Coordinated Universal Time" — the time zone log timestamps are stored in. Adjust for local time when reading logs. |
| **WAC (Weighted Average Cost)** | The running average purchase cost of a product, from goods receipts. Used for margins, profit and cost-plus pricing. See Chapter 08. |
| **Warehouse** | A place stock is held. You create one per real location. See Chapter 04. |
| **Warranty Check** | A look-up tool showing whether a delivered item is still under warranty on a given date. See Chapter 05. |
